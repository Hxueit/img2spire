# img2spire

为Windows环境下《杀戮尖塔 2》(Slay the Spire 2) 联机绘图(单机也可以)设计的图像转鼠标轨迹工具。

### 功能特点
- **边缘识别**：Canny 边缘检测 + 细化，将边缘追踪为单向折线，每条边只画一遍。
- **路径优化**：Douglas-Peucker 抽稀，并按最近邻重新排列笔画顺序，减少抬笔空走。
- **暴力填涂**：按行间距蛇形扫描，完整填满绘图区。可以被用来实现类似战争迷雾的效果。
- **轨迹预览**：显示预计耗时、落笔/空走长度，可显示抬笔空走路径；绘画时实时显示进度。
- **多显示器**：框选区域时自动截取程序窗口所在的显示器，副屏同样可用。
- **设置自动保存**：参数、绘制区域、热键以及上次加载的图片会在下次启动时恢复。
- 所有绘画行为均默认模拟鼠标右键按下/抬起，适配游戏内的绘图系统。

### 使用步骤
1. 点击「加载图片」选择图片（透明背景会被当作白色处理）。
2. 调整 Canny 阈值与防抖精度，在右侧预览中确认效果。
3. 将程序窗口移到游戏所在的显示器，点击「手动框选作画区域」框出游戏画布。
4. 切换到游戏，按开始热键绘画。

### 默认快捷键
| 按键 | 功能 |
| --- | --- |
| `F9` | 开始边缘绘画 |
| `F11` | 暴力填涂绘画区域 |
| `F10` | 停止 |
| `F8` | 暂停 / 继续 |

热键可在「热键设置」中修改，支持组合键，如 `ctrl+F9`、`alt+shift+KeyD`。

### 注意事项
- 如果游戏以管理员身份运行，本程序也需要以管理员身份运行，否则模拟的鼠标输入会被系统拦截。
- 暂停后可以自由移动鼠标，继续时会先回到断点再落笔。

### 下载与编译
可在 GitHub Actions 的构建产物或 Releases 中下载编译好的 `img2spire.exe`。

自行编译需安装 Rust 环境，在项目根目录执行：
```bash
cargo run --release
```
