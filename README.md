# img2spire

为Windows环境下《杀戮尖塔 2》(Slay the Spire 2) 联机绘图(单机也可以)设计的图像转鼠标轨迹工具。

### 功能特点
- **边缘识别**：自动解析图像边缘并转换为优化的鼠标绘画轨迹。
- **暴力填涂 (F11)**：快速填满整个绘图区。可以被用来实现类似战争迷雾的效果。
- 所有绘画行为均默认模拟鼠标右键按下/抬起，适配游戏内的绘图系统。

### 快捷键
- `F9`：开始边缘绘画
- `F11`：暴力填涂绘画区域
- `F10`：停止 
- `F8`：暂停 / 继续

### 编译运行
确保已安装 Rust 环境，在项目根目录执行：
```bash
cargo run --release
```
